# Flutter Apps

A collection of cross-platform Flutter applications, each exploring a different domain — IoT/hardware integration, real-time tracking, and conversational interfaces.

## 📱 Projects

### GuardianPod — IoT Child Safety Companion App
`Flutter · Dart · Firebase · BLE · Geolocator · Provider`
Cross-platform app integrating Bluetooth Low Energy (BLE) with ESP32 hardware via GATT characteristic subscriptions for real-time SOS alerts. Includes live GPS tracking with breadcrumb trails, geofence alerts, and push notifications.

### SafariSync — Smart Wildlife Intelligence System
`Flutter · Dart · Firebase · fl_chart · WebView · FCM`
A 12+ screen wildlife safari management platform with real-time animal tracking, vehicle route simulation, Firebase Realtime Database telemetry, slot-based ticket booking with QR codes, and role-based access (tourist/driver/admin).

### Smart Waste Management — IoT Waste Monitoring App
`Flutter · Dart · Firebase RTDB · IoT Sensors`
Reads real-time load-cell sensor data via Firebase Realtime Database with a threshold-based alert system. Built as part of the winning submission (1st Runner-Up) at DJS Strike, a 50+ team hackathon.

### Peblo Story Buddy
`Flutter · Dart`
An interactive storytelling app.
